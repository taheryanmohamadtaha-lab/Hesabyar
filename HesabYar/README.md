# حساب‌یار 🌸
اپ اندروید ثبت خودکار درآمد و هزینه از روی پیامک‌های بانکی (بانک ملت)

ساخت APK بدون Android Studio:
1. یک ریپوی خصوصی در GitHub بساز و همه‌ی فایل‌های همین پوشه را آپلود کن (پوشه‌ی .github هم باید باشد).
2. تب Actions → «Build APK» → Run workflow (یا خودکار بعد از push اجرا می‌شود).
3. بعد از چند دقیقه در همان صفحه، بخش Artifacts → HesabYar-APK را دانلود کن؛ داخل zip فایل app-debug.apk است.
4. APK را روی گوشی نصب کن (اجازه‌ی نصب از منبع ناشناس).
